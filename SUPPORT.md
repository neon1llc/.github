# Support

I maintain neon1's public repositories on a best-effort basis, with no response-time commitment.

- **A bug or wrong result:** open an issue with what you ran, what you expected, and what happened.
- **A question about a tool:** read the repository's README first, then open an issue.
- **Paid work or help with your own setup:** see [neon1.tech](https://neon1.tech).

Each README states the repository's status and what has been tested. The tools are version 0.x. The training material is education, not legal advice, an audit, or a certification.
