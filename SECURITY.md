# Reporting a security problem

This is the default policy for neon1 repositories that don't have their own `SECURITY.md`.

- **A security problem in code:** report it privately through GitHub's "Report a vulnerability" button on the repository. If the button isn't there, email security@neon1.tech. Please don't open a public issue.
- **Wrong or unsafe advice in training material:** open an issue with the page link and what's wrong. If following the advice could hurt someone right now, put `[urgent]` in the title.

You'll get a reply within a few days, and credit in the changelog if you want it. neon1 is one person and offers no service-level guarantee.
