# Reporting a security problem

This is the default policy for neon1 repositories without their own `SECURITY.md`.

- **A security problem in code:** report it privately with GitHub's "Report a vulnerability" button on the repository. If the button isn't there, email security@neon1.tech. Don't open a public issue.
- **Wrong or unsafe advice in training material:** open an issue with the page link and what's wrong. If the advice could hurt someone right now, put `[urgent]` in the title.

I reply within a few days and credit you in the changelog if you want. neon1 is one person with no service-level guarantee.
