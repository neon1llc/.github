# Contributing

Use the issue forms for reproducible bugs and documentation fixes. Report security problems privately as described in [SECURITY.md](SECURITY.md). Don't put passwords, tokens, private sign-in links, or customer data in issues or pull requests.

## Propose a change

1. Read the repository README and follow its setup, branch, and check instructions.
2. Open a focused pull request with the problem, the change, and the checks you ran.
3. Keep generated files, unrelated cleanup, and credentials out of the change.
4. A maintainer reviews it and may ask for changes.

## Licenses

Each repository sets its own terms in its `LICENSE`, `LICENSE-CODE`, `NOTICE`, and `TRADEMARK.md` files. Code and writing can have different terms. Name any license conditions on your contribution in the pull request.
